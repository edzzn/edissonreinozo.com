# Zed Editor Keyboard Shortcuts

## Essential Shortcuts

### General
- `Cmd+Shift+P` (Mac) / `Ctrl+Shift+P` (Linux/Windows) - Command Palette
- `Cmd+,` / `Ctrl+,` - Open Settings
- `Cmd+K, Cmd+T` - Change Theme
- `Cmd+Q` / `Ctrl+Q` - Quit Zed

### File Navigation
- `Cmd+P` / `Ctrl+P` - Quick File Open
- `Cmd+Shift+F` / `Ctrl+Shift+F` - Search in Project
- `Cmd+E` / `Ctrl+E` - Recent Files
- `Cmd+Shift+E` / `Ctrl+Shift+E` - Toggle File Explorer

### Editing
- `Cmd+D` / `Ctrl+D` - Select Next Occurrence
- `Cmd+Shift+L` / `Ctrl+Shift+L` - Select All Occurrences
- `Alt+Up/Down` - Move Line Up/Down
- `Cmd+/` / `Ctrl+/` - Toggle Comment

### View/Panels
- `Cmd+\` / `Ctrl+\` - Split Editor
- `Cmd+B` / `Ctrl+B` - Toggle Sidebar
- `Cmd+J` / `Ctrl+J` - Toggle Terminal

### Collaboration
- `Cmd+Shift+C` / `Ctrl+Shift+C` - Start/Stop Collaboration

## Customization

### Access Default Keybindings
To see all default shortcuts:
1. Open Command Palette (`Cmd+Shift+P` / `Ctrl+Shift+P`)
2. Search for "zed: open default keymap"

### Custom Keybindings
- Zed reads custom keybindings from: `~/.config/zed/keymap.json`
- To open your custom keymap, use the Command Palette and search for "open keymap"
